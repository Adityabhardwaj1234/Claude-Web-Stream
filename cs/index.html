Claude Stream

A local, encrypted, resumable streaming gateway for the Anthropic Messages API.

  1. Create a local account. Your password derives the key that encrypts your data.
  2. Add your Anthropic API key. It is stored encrypted and never shown again in full.
  3. Create a gateway key and point your application at http://127.0.0.1:8787/v1.

Connect an application

curl http://127.0.0.1:8787/v1/messages \
  -H "x-api-key: csk_YOUR_GATEWAY_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"MODEL_ID","max_tokens":256,"messages":[{"role":"user","content":"Hello"}]}'

Add "stream": true for server-sent events. Pings are forwarded as keep-alives and are not stored. gateway.error and gateway.cancelled are gateway-owned events; everything else is the upstream event, unchanged.
